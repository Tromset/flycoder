Configuration du projet

Les paramètres sont lus dans .flycoder.json à la racine de votre projet.

Ajoutez un vérificateur, par exemple :
{"checks": {"test": ["node", "--test"]}}
Relancez FlyCoder après modification. Tous les langages disposant d’un compilateur ou d’un interpréteur local peuvent utiliser un vérificateur personnalisé.
